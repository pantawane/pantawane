## 🔥 Featured Projects

### 🤖 [ResumeCraft AI — AI Career Platform](https://github.com/pantawane/ai-resume-builder)

A free, open-source AI career platform featuring **13 career tools** to help users improve resumes and prepare for job applications.

- ✅ ATS scoring, AI resume templates, cover-letter generation, interview preparation, and job tracking.
- 🔐 Secure REST APIs with Express 5, TypeScript, JWT authentication, password hashing, Helmet, and rate limiting.
- 🧪 Jest tests, Docker containerization, and GitHub Actions CI/CD.
- 🧩 ImageKit integration and a RAG-inspired resume bullet suggestion system.

**Tech:** MERN · TypeScript · Groq LLaMA 3.3 · Redux Toolkit · Docker · GitHub Actions · Jest · ImageKit

### ✈️ [TripMate AI — Multi-Agent Travel Planner](https://github.com/pantawane/Tripmate-AI)

An AI travel planner that turns natural-language trip requests into structured travel plans using coordinated specialist agents.

- 🧠 Orchestrates flight research, hotel research, itinerary planning, and final responses with **LangGraph**.
- ✈️ Integrates **AviationStack** for flight information and **Tavily** for hotel research.
- ⚡ Uses a **FastAPI** backend with REST endpoints and a lightweight web interface.
- 💾 Persists conversation history and shared workflow state with **PostgreSQL**.

**Tech:** Python · LangGraph · LangChain · FastAPI · Groq · PostgreSQL · Tavily · AviationStack · HTML/CSS/JavaScript
